# Slipstream demo project

This folder plays the part of your project **after the agent has worked on it**:
`src/greet.ts` was changed and `src/math.ts` is new.

`.slipstream/practice/` is your practice folder, as "Start Practice → Last commit" would create it:
the project as it was before the agent's changes. Its `.slipstream/link.json` points back here.

1. Open `.slipstream/practice/src/greet.ts`. Grey `▸` markers show where code is missing;
   struck-through code is code to delete. Press `Alt+]` to jump to the next change.
2. Type the ghost text. `Tab` accepts the next word, `Shift+Tab` the rest of the line.
3. Create `.slipstream/practice/src/math.ts` yourself (it exists only in the project) and start typing.
4. Edit a file in `src/` (as the agent would) and watch the ghost text update.
