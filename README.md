# Slipstream

**Draft behind your AI agent.** A VS Code extension: the agent writes the code in your project as usual;
you retype its changes yourself in a practice folder, with what's left to type shown as ghost text
(`Tab` a word, `Shift+Tab` a line). Or replay any repository's git history, one commit at a time.

The extension lives in [`vscode/`](vscode/):

* [README](vscode/README.md) — what it does and how to use it
* [CONTRIBUTING](vscode/CONTRIBUTING.md) — run it from source, test, package, publish
* [PLAN](vscode/PLAN.md) — the design and its milestones
* [CHANGELOG](vscode/CHANGELOG.md)
